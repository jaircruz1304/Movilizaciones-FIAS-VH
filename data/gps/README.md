# Datos GPS no versionados

Desde la versión 2.0, los JSON GPS de producción no se almacenan en GitHub ni se publican en GitHub Pages.

GitHub Actions los genera y mantiene en la carpeta protegida de SharePoint:

`Movilizaciones-FIAS/GPS/Publicados`

Este directorio se conserva únicamente para pruebas locales opcionales del parser/validador.
